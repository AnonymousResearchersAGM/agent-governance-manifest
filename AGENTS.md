# Agent Instructions

This repository uses Agent Governance Manifest (AGM).

Before making or submitting changes, read `.agm/manifest.yml` and the policy
files it references.

AGM is the canonical governance source. This file is only a discovery pointer.
For vNext development, follow `.agm/agents/contributor_protocol.md` or
`.agm/agents/maintainer_protocol.md` as appropriate.

Agents may prepare assessments and evidence, but may not perform human
attestation, maintainer verification, override, or final decisions. Do not
invent evidence; expose missing evidence and pause for explicit human action.
Final review and acceptance remain with human maintainers.
