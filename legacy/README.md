# Legacy Experimental Materials

This directory contains historical experimental materials from earlier AGM prototype iterations.

These files are not part of the AGM v0.1.0 Community Draft core. They are retained only as historical context and should not be treated as canonical rules, current schemas, current examples, or required workflows.

The AGM v0.1.0 canonical governance source is:

- `.agm/manifest.yml`
- the risk-zone file referenced by the manifest
- the evidence-requirement file referenced by the manifest

AGM v0.1.0 is not an agent trace system, provenance log system, AI detector, PR template, or automatic merge/reject tool. Final decisions remain with human maintainers.
