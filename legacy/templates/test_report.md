# AGM Test Report

## Structured Fields

- commands:
  - "<test command>"
- environment: "<local/ci environment and Python version if known>"
- outcomes:
  - command: "<test command>"
    result: "<pass|fail|not run>"
    summary: "<short output summary>"
- coverage_notes: "<what behavior the tests cover>"
- failures:
  - "<failure or none>"

## Notes

The purpose of this report is to make test evidence inspectable by maintainers and review agents.
