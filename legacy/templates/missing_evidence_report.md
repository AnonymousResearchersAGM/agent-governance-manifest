# AGM Missing Evidence Report

## Structured Fields

- changed_files:
  - "<path>"
- independently_classified_risk_level: "<low|medium|high|critical>"
- required_evidence:
  - "<evidence item>"
- submitted_evidence:
  - "<evidence item>"
- missing_evidence:
  - "<missing evidence item or none>"
- blocking_recommendation: "<true|false>"
- reason: "<short factual reason>"

## Boundary

This report identifies evidence gaps. It does not evaluate undisclosed prompts or private reasoning.
