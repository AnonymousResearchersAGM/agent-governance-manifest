# AGM evaluation continuity

The v0.1 controlled evaluation is not a test of a discarded product. It supports retained mechanisms: structured externalization, risk-state recoverability, evidence-state recoverability, human-confirmation recoverability, gate-state recoverability, technical-review readiness, and the final-acceptance boundary.

v0.2 and Phase 2.1 add compiled contribution state, commit-bound materials, responsibility routing, lifecycle orchestration, scoped repair, authority enforcement, PR-native diagnosis, concrete inspection objects, explicit action-effect boundaries, and sidecar storage. Existing v0.1 participants did not validate those additions or the Phase 2.1 interface.

Claim-to-evidence mapping has three layers: foundational reviewer-side externalization uses the existing v0.1 controlled evaluation; lifecycle and architectural correctness uses deterministic cases and automated tests; PR-native usability requires a future formative cognitive pilot and formal usability evaluation. Incremental experiments test only the new mechanisms.

Phase 2.1.1 strengthens lifecycle and architectural correctness only. It does not claim that a user study has validated the rebuilt PR-native interface.
